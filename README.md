Проект содержит `hw1/` с собственным `CMakeLists.txt`, тестами корректности и отдельной программой измерения производительности.

Основная инструкция: [hw1/README.md](hw1/README.md).
Подготовка к защите: [hw1/DEFENSE.md](hw1/DEFENSE.md).
Результаты проверок на Windows/MSVC: [hw1/results/WINDOWS_RUN_REPORT.md](hw1/results/WINDOWS_RUN_REPORT.md). Предыдущий запуск на Linux описан в [hw1/results/RUN_REPORT.md](hw1/results/RUN_REPORT.md).
Участие AI: [hw1/AI_CONTRIBUTIONS.md](hw1/AI_CONTRIBUTIONS.md).

Если проект получен архивом, исходные файлы можно использовать сразу. В архив также включён `git-history.bundle`, содержащий коммит с явным описанием помощи AI. Чтобы получить репозиторий с этой историей, из папки распакованного архива выполните:

```text
git clone git-history.bundle cpp-homework
```

Для переноса в уже существующий учебный репозиторий скопируйте папку `hw1/` и используйте описание коммита из `hw1/COMMIT_MESSAGE.txt`. Сам файл с описанием не заменяет сообщение реального коммита.
