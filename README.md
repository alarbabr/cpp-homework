# ДЗ 1 — сортировка слиянием

`hw1/my_sort.hpp` — реализация `mySort`, `hw1/point.hpp` — точки и сравнение по расстоянию. Стандарт C++17, время O(n log n), дополнительная память O(n). Сортировка не гарантирует устойчивость.

## Сборка и запуск

В Windows откройте **x64 Native Tools Command Prompt for Visual Studio** с установленными C++, CMake и AddressSanitizer. Из корня репозитория выполните:

```bat
hw1\run_windows.cmd
```

Скрипт последовательно собирает и запускает:

- `hw1/tests/` — проверки корректности в **Debug с `/fsanitize=address`**.
- `hw1/bench/` — замеры в отдельной **Release-сборке с `/O2` без санитайзеров**. Цифры выводятся в консоль и сохраняются в [hw1/bench/results.csv](hw1/bench/results.csv).

## Что показать на защите

Тесты проверяют порядок и сохранность элементов для `int` и `Point`: пустой вход, один элемент, равные и повторяющиеся значения, прямой и обратный порядок, случайные данные. Есть крайние значения `int`, равноудалённые точки, другой компаратор, массив и поддиапазон. Эти случаи проверяют границы диапазона, работу сравнения и сохранение повторов.

Замеры сравнивают `mySort` и `std::sort` на размерах 1000, 10000, 100000 и 1000000; также проверяется отсортированный вход размера 100000. Рост размера в десять раз показывает изменение времени с увеличением входа. Результат — медиана пяти измерений после прогрева; подготовка данных и проверка результата находятся вне таймера, внутренние выделения памяти сортировки входят в замер.

Сохранённые замеры получены 10.10.2026 на Intel Core i9-13900HX, Windows, MSVC 19.51.36260.0 x64. Debug: 32/32 проверки прошли. Повторный запуск обновляет CSV; время зависит от нагрузки компьютера.
