- ОС: Linux-6.18.44-x86_64-with-glibc2.39.

- Release: `-O2 -DNDEBUG`; санитайзеры отсутствуют.
- Итоговые сборки завершились без предупреждений компилятора.

## Корректность

Успешно выполнены все 32 проверки. CTest зарегистрировал один исполняемый тест, внутри которого выполняются 32 отдельных случая. Все они напечатаны в `correctness.txt`. Проверяются оба типа, порядок и сохранность элементов, дополнительные компараторы, int[] и поддиапазон.

В контейнере отключена только проверка утечек LeakSanitizer: `ASAN_OPTIONS=detect_leaks=0`, поскольку окружение не разрешает ей исследовать потоки процесса. AddressSanitizer и UndefinedBehaviorSanitizer оставались включены. Отключение утечек не требуется добавлять в Windows-скрипт.

## Отсортированный вход

- int: `mySort(sorted) / mySort(random)` при n=100000 = 0.629228.
- Point: `mySort(sorted) / mySort(random)` при n=100000 = 0.558530.

В этом запуске отсортированный вход оказался быстрее случайного для обоих типов. Деградации не наблюдалось. Отношение mySort/std::sort на отсортированных данных может быть больше, потому что std::sort тоже ускоряется; это не означает ухудшение самой mySort.
