# Проверка ДЗ 1 на Windows/MSVC

Запуск выполнен 10 октября 2026 года (Москва) на компьютере с Intel Core i9-13900HX и Windows build 26300.9550. Использованы Visual Studio Community 18, MSVC 19.51.36260.0, CMake 4.3.1-msvc1 и генератор `Visual Studio 18 2026`, x64. В обоих случаях стандарт C++17. В сохранённых логах абсолютный путь к рабочему каталогу сокращён до `<repo>`; команды, флаги и результаты оставлены без изменений.

## Корректность: Debug с AddressSanitizer

Отдельный каталог `build-debug`, цель `hw1_tests`. В фактической команде компиляции есть `/fsanitize=address`, `/Od`, `/Zi`; линковка выполнена с `/INCREMENTAL:NO`. Сборка завершилась без предупреждений и ошибок. CTest запускался из среды `vcvars64.bat`, чтобы загрузчик нашёл DLL рантайма ASan. Итог: **32 из 32 проверок прошли**, CTest: **1/1 Passed** за 16,21 с. Полный список случаев и вывод CTest сохранены в [correctness_windows.txt](correctness_windows.txt), команда компиляции — в [debug_build_windows.txt](debug_build_windows.txt).

Проверяются `int` и `Point`: пустой и одиночный входы, отсортированные и обратные данные, равные и повторяющиеся элементы, два фиксированных seed для размеров 10, 1000 и 100000. Дополнительно проверяются крайние `int`, отрицательные значения, равноудалённые точки, другой компаратор, обычный массив и поддиапазон. Проверки подтверждают и порядок, и сохранность всех элементов.

## Производительность: Release без санитайзера

Отдельный каталог `build-release`, цель `hw1_bench`. Фактическая команда компиляции содержит `/O2`, `/DNDEBUG` и не содержит `/fsanitize=address`. Сборка завершилась без предупреждений и ошибок. ## Повторение

Откройте `x64 Native Tools Command Prompt for Visual Studio`, перейдите в корень репозитория и выполните `hw1\run_windows.cmd`. Скрипт собирает и запускает обе конфигурации. Среда Visual Studio нужна для доступности DLL AddressSanitizer при выполнении Debug-тестов.
